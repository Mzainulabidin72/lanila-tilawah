Yth. Tim QuranEnc / Lajnah Pentashihan Mushaf Al-Qur'an (LPMQ) Kementerian Agama RI,

Kami mengembangkan aplikasi pendamping Al-Qur'an bernama **Lanila Tilawah** ([deskripsi singkat, URL]). Aplikasi menampilkan teks Arab Al-Qur'an (Tanzil Quran Text, tidak diubah) bersama terjemahan Indonesia Kementerian Agama RI ([versi/edisi yang dipakai], diunduh dari QuranEnc.com, key `indonesian_affairs`).

Kami berencana [gratis / dengan iklan / dengan langganan atau fitur berbayar] dan ingin memastikan penggunaan yang sah. Mohon konfirmasi tertulis:

1. Apakah terjemahan tersebut boleh ditampilkan dalam aplikasi kami, termasuk bila aplikasi bersifat komersial ([jelaskan model bisnis])?
2. Apakah kami wajib mencantumkan atribusi dengan format tertentu? Saat ini: "Terjemahan: Kementerian Agama RI, diterbitkan melalui QuranEnc.com, versi [x]".
3. Apakah catatan kaki wajib ditampilkan bersama terjemahan?
4. Apakah aplikasi Al-Qur'an digital memerlukan proses pentashihan/izin dari LPMQ? Jika ya, mohon petunjuk prosedurnya.
5. Apakah ada ketentuan tambahan (misalnya pembaruan versi, penyimpanan data di server kami)?

Kami berkomitmen menampilkan terjemahan tanpa perubahan, menyebut sumber dan versi, serta tidak menempatkan iklan yang tidak pantas di dekat teks.
